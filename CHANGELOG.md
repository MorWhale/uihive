# Changelog

All notable changes to this project will be documented in this file.

## [0.0.1]

### Added

- CLI commands: `init`, `discover`, `add`, `publish`, `list`, `info`, `serve`, `remove`, `search`.
- mDNS discovery (`bonjour-service`), registry manifest handling, `@swc/core` AST parsing.
- i18n CLI (English/French) via `UIHIVE_LANG` / `LANG`.
- Dry-run support on `add`, `publish`, `remove`.
- Registry validation, backups on publish, versioning fields, tests (Vitest), CI (GitHub Actions), Prettier/ESLint.
